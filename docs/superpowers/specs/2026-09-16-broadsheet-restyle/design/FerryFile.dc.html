FerryFile · Android · v0.1.0Broadsheet restyle · turn 1

A newsprint skin for a cable‑free file ferry

Same app, same features, same two screens. What changes is the ink: Source Serif 4 on paper, process cyan for anything you can touch, magenta held back for warnings, and hierarchy carried by type scale and whitespace instead of Material cards and elevation.

Read from the codebase

HomeScreen.kt, SettingsScreen.kt, Theme.kt/Color.kt, strings.xml (en + ru), webui/login.html, files.html, style.css, i18n.js. Every label below is a real string resource; the recreation uses the M3 fallback purple from Color.kt.

Assumptions

Restyle only — no QR code, no history, no new settings. Folder picking stays a system SAF dialog. The browser UI keeps its markup ids so the restyle is a CSS swap.

Language coverage

EN and RU are paired side by side on the recreation (1a), the settings screen (1f) and the browser (1g). The three home directions are EN only so they compare cleanly; Russian runs ~30% longer, which is why every label is set flush-left with no fixed-width chrome.
